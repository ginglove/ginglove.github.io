POST /pet/{petId}/uploadImage
Uploads an image for a pet

Request Headers & Parameters

Content-Type: multipart/form-data
Accept: application/json
Path Param: petId (integer, required)

Request Body Format

Form-Data Payload:
  - additionalMetadata: "Front profile image" (string, optional)
  - file: [binary image file data] (file, optional)

HTTP Status Codes & Response Body

200 OK Header: Content-Type: application/json 
{
  "code": 200,
  "type": "unknown",
  "message": "additionalMetadata: Front profile image\nFile uploaded to ./upload/file.png, 15432 bytes"
}
