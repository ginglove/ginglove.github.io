PHẦN 1: MODULE XÁC THỰC (AUTHENTICATION)

📚 1.1. POST /auth/register (Ref: Trang 7, 8) [cite: 1]

Field NameTypeRequired?Validation Rules / Description
full_nameStringYes (✓)2-100 ký tự, chỉ chữ cái và khoảng trắng [cite: 1].
emailStringYes (☑)Định dạng RFC5321, tự động lowercase [cite: 1].
usernameStringYes (☑)Regex ^[a-zA-Z0-9_]{6,50}$, unique [cite: 1].
passwordStringYes (☑)>= 8 ký tự, bắt buộc có chữ HOA + thường + số [cite: 1].
confirm_passwordStringYes (☑)Phải khớp hoàn toàn với password [cite: 1].
phone_numberStringNo10 chữ số, bắt đầu bằng 0 (Optional) [cite: 1].
departmentStringNoTối đa 100 ký tự (Optional) [cite: 1].
THÀNH CÔNG (201 Created) [cite: 1]:
{"success": true, "data": {"id": "uuid", "email": "...", "status": "INACTIVE"}, "timestamp": "..."}
THẤT BẠI:
• 400 Bad Request: ERR_VALIDATION hoặc ERR_PASSWORD_MISMATCH [cite: 1]
• 409 Conflict: ERR_EMAIL_EXISTS hoặc ERR_USERNAME_EXISTS [cite: 1]
• 422 Unprocessable Entity: ERR_PASSWORD_WEAK [cite: 1]
• 429 Too Many Requests: ERR_RATE_LIMIT (>5 req/phút/IP) [cite: 1]
• 503 Service Unavailable: ERR_EMAIL_SERVICE_DOWN [cite: 1]
